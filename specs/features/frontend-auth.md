# Feature: Frontend Authentication

## Scope
Phase II – Basic Authentication UI

## Responsibilities
- Allow user signup
- Allow user login
- Store JWT token
- Attach JWT to API requests

## Constraints
- No advanced validation
- No OAuth
- No session cookies
- JWT stored in localStorage

## Acceptance Criteria
- User can sign up
- User can log in
- JWT is saved on login
- Authenticated requests include JWT
